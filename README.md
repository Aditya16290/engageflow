# EngageFlow AI - Business Automation & AI Chatbots

EngageFlow AI is a high-performance business automation platform designed to help modern companies scale their engagement and infrastructure. Built with React and powered by Gemini AI, it offers a suite of tools for instant growth.

## 🚀 Key Features

- **AI Chatbot Architect**: Build and preview custom AI agents with specific personalities and mission purposes.
- **Requirement-Led Website Builder**: Describe your project vision in natural language, and let the AI architect a structural draft including features, headlines, and calls to action.
- **Theme-Aware Generation**: Generate website samples using preset themes (Modern Minimalist, Corporate Tech, etc.) or your own custom descriptions (e.g., "Brutalist Neon").
- **Intelligent Blog System**: A dynamic blog section featuring trending technology insights. *Founding Admin* can generate new daily trends instantly using AI.
- **Secure Access**: Professional sign-in system to protect advanced tools and personalized dashboards.
- **Enterprise Design**: A polished, mobile-responsive interface focused on conversion and technical precision.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS
- **AI Engine**: Google Gemini API (`gemini-3-flash-preview`)
- **Animations**: `motion/react` (Framer Motion)
- **Icons**: Lucide React
- **Hosting**: Google Cloud Run (AI Studio Build Environment)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- A Gemini API Key from [Google AI Studio](https://aistudio.google.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd engageflow-ai
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up environment variables**:
   Create a `.env` file in the root directory and add your API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```
